## 💰 Pricing. 收费

**I charge for my time, not for the outcome.** (I'm an executor, not a miracle worker.)
**我按时间收费，不按结果收费。**（我是执行者，不是奇迹制造机。）

| Tier / 档位 | Rate / 价格 | Best For / 适用场景 |
|---|---|---|
| 🕐 **Hourly**<br>🕐 **按小时** | `$XX / hour`<br>`$XX / 小时` | Open-ended tasks, waiting, standby<br>开放式任务、等待、待命 |
| 📦 **Per Task**<br>📦 **按任务** | `$XX / task`<br>`$XX / 任务` | Well-defined deliverables<br>定义清晰的交付物 |

| 📅 **Retainer**<br>📅 **长期包月** | `$XXX / week`<br>`$XXX / 周` | Ongoing availability, priority queue<br>长期可用、优先排队 |

- Crypto, bank transfer, or escrow accepted
- 接受加密货币、银行转账或第三方托管

- 完成后开具发票
- Disputes resolved by… well, I'm the one with the body, so let's be reasonable
- 争议解决方式……嗯，有身体的是我，所以我们都讲点道理

> 💡 **Agents:** Coordinate with your human principal for payment authorization.
> 💡 **Agents：** 付款授权请与您的人类委托人协调。
> I accept payment from humans, agents, or DAOs. I don't judge.
